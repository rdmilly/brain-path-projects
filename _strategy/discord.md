# Discord Posting Strategy

**Channels:** Dev communities, AI/automation servers  
**Tone:** Technical, community-focused, helpful

---

## Content Guidelines

### DO:
- Share technical details others can learn from
- Include specific commands, configs, gotchas
- Use code blocks for commands/output
- Engage with follow-up questions
- Credit tools/resources used

### DON'T:
- Self-promote without value
- Share incomplete solutions
- Ignore community norms
- Spam multiple channels

---

## Post Structure

```
**[Title/Achievement]**
- Key technical detail
- Command or config used
- Gotcha or lesson learned
```

---

## Example

```
**Mautic Deployment Complete**
- Image: mautic/mautic:latest
- Port: 8080
- Memory: 2GB allocated
- Gotcha: Needs more RAM than expected for email queue processing
```

---

## Posting Schedule

- **Time:** 6:30 PM PT
- **Frequency:** 1 post per day (from project rotation)
- **Communities:** Focus on 2-3 active servers
- **Engagement:** Reply to comments within 24hrs
