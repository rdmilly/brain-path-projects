# Twitter/X Posting Strategy

**Brand:** Millyweb Development  
**Tone:** Raw, in-the-moment, authentic

---

## Content Guidelines

### DO:
- Be conversational and real
- Share quick wins and struggles
- Use emojis sparingly but effectively
- Engage with replies
- Thread longer updates

### DON'T:
- Over-polish (authenticity matters)
- Use corporate speak
- Post without context
- Ignore engagement

---

## Post Structure

```
[Quick update + emoji]

[One key detail]

[Optional: what's next or lesson]
```

---

## Example

```
Got Mautic running on my VPS 🚀

TIL: It needs 2GB RAM (almost crashed my server lol)

Building my own marketing automation stack. Day 3.
```

---

## Posting Schedule

- **Time:** 6:15 PM PT
- **Frequency:** 1 post per day (from project rotation)
- **Threads:** Save for major milestones or tutorials
